Questions fréquentes

Combien de temps faut-il pour recevoir mon site ?

Cela dépend de la formule choisie. Envoyez-nous un message sur WhatsApp avec la date de votre événement, nous vous confirmons le délai.

Mes invités doivent-ils installer une application ?

Non. L'invitation s'ouvre depuis un lien, directement dans le navigateur du téléphone.

Comment fonctionne le contrôle à l'entrée ?

Chaque invité reçoit un QR code personnel. Vous le scannez avec SmartCheck et l'invité est marqué comme présent.

Puis-je utiliser SmartEvent pour autre chose qu'un mariage ?

Oui : anniversaires, fêtes privées, conférences et lancements de produits. Pour les entreprises, nous établissons un devis.
